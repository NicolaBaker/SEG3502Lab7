Cloner le projet dans le terminal : git clone https://github.com/NicolaBaker/SEG3502Lab7.git
Démarrer la base de données MySQL Ouvrir Docker Desktop et démarrer le conteneur MySQL : docker start docker-mysql 
Si le conteneur n'existe pas encore, il faut le créer avec la configuration MySQL du laboratoire. 
Démarrer le serveur Spring Boot Ouvrir un terminal dans le dossier server : cd server .\gradlew.bat bootRun
Le serveur utilise l’adresse http://localhost:8080. 
Démarrer l’application Angular Ouvrir un autre terminal dans le dossier client : cd client npm install npx ng serve
Ouvrir l’application Dans le navigateur, entrer : http://localhost:4200/
Cliquer sur Authors dans le menu entrer un ID d’auteur et cliquer sur Search pour voir les informations.
